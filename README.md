# Распознавание планов помещений и извлечение легенд (Indoor Blueprint Recognition)

Данный проект предназначен для автоматического анализа планов помещений (Blueprints), детекции графических элементов легенды и распознавания текстовых описаний с помощью OCR.

Проект оптимизирован для работы как на CPU, так и на **GPU (видеокарте)** для значительного ускорения распознавания текста (OCR).

---

## 📋 Системные требования

* **ОС**: Windows 10 / 11
* **Python**: Версия 3.8 – 3.11 (рекомендуется 3.10)
* **Git**: Для клонирования репозитория
* **GPU (Видеокарта)**: NVIDIA с поддержкой CUDA (драйверы должны быть обновлены)

---

## 🚀 Пошаговая установка на новом компьютере с GPU

### Шаг 1. Клонирование репозитория
Откройте терминал (PowerShell или Командную строку) и выполните:
```bash
git clone <URL_ВАШЕГО_РЕПОЗИТОРИЯ>
cd <ИМЯ_ПАПКИ_ПРОЕКТА>
```

### Шаг 2. Создание виртуального окружения
Запустите скрипт автоматической настройки (он создаст виртуальное окружение `.venv` и настроит структуру папок):
```bash
setup.bat
```
*Примечание: Если во время установки зависимостей возникнут ошибки с PyTorch, перейдите к Шагу 3.*

### Шаг 3. Настройка GPU (CUDA) для ускорения EasyOCR
По умолчанию `pip install` устанавливает CPU-версию PyTorch. Чтобы задействовать видеокарту NVIDIA:

1. Активируйте виртуальное окружение:
   ```powershell
   .venv\Scripts\activate
   ```
2. Установите PyTorch с поддержкой CUDA (выберите версию CUDA, соответствующую вашей системе, например, CUDA 12.1):
   ```bash
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121 --force-reinstall
   ```
   *Если у вас более старая видеокарта или CUDA 11.8:*
   ```bash
   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu118 --force-reinstall
   ```

3. Проверьте доступность видеокарты в Python:
   ```bash
   python -c "import torch; print('CUDA available:', torch.cuda.is_available()); print('Device:', torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'None')"
   ```
   Вы должны увидеть `CUDA available: True` и модель вашей видеокарты.

### Шаг 4. Загрузка предобученных моделей OCR
Вы можете запустить скрипт PowerShell для предварительной загрузки моделей детекции текста (CRAFT) и распознавания (Cyrillic + Latin):
```powershell
powershell -ExecutionPolicy Bypass -File download_models.ps1
```
*Если скрипт не запущен, EasyOCR автоматически скачает эти модели при первом запуске программы (потребуется интернет-соединение).*

## 💻 Запуск проекта

В проекте предусмотрено два режима работы:

### 1. Веб-интерфейс (Streamlit UI) — Рекомендуется
Красивый интерактивный интерфейс в браузере, где можно загружать PDF-файлы планов, настраивать параметры детекции и скачивать результаты в Excel.
* Для запуска дважды кликните по файлу: **`run_ui.bat`**
* Или запустите из активированного окружения:
  ```bash
  streamlit run run_ui.py
  ```

### 2. Консольный пайплайн (CLI)
Для пакетной обработки планов без запуска интерфейса.
* Дважды кликните по файлу: **`run_pipeline.bat`**
* Или запустите из консоли:
  ```bash
  python main.py
  ```

## 📁 Структура папок проекта

* `config/config.yaml` — Общие конфигурации проекта (пороги уверенности детектора, настройки EasyOCR).
* `data/raw/` — Папка для исходных PDF планов.
* `data/templates/` — Шаблоны элементов легенды для поиска соответствий (Template Matching).
* `output/` — Сюда сохраняются результаты работы (Excel-файлы, вырезанные изображения легенд и визуализация детекции).
* `src/` — Исходный код пайплайна (препроцессинг, детекция, OCR, UI).
